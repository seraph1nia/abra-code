# Choosing a self-hosted agent memory for AbraCode

November 22, 2026. Basic Memory ranks first for this project because a new worker can open a specific, human-editable note from its own repository plus a deliberately shared collection. The operator can inspect the same bytes in Obsidian, and offline text search works with an empty model cache. Thoughts already provides private capture. The implemented bridge publishes a selected passage after the operator chooses its audience. [Basic Memory](https://github.com/basicmachines-co/basic-memory) · [Local verification](supported-apis.md#basic-memory-100)

Neo4j adds value when a question requires following relationships across lessons. For example, “Which other services use a dependency version implicated in two independently verified recoveries?” would need service, dependency, incident and evidence relationships. Neo4j can query those paths directly. Graphiti can also extract entities and track when facts were superseded. Operating all three today would add another service, a schema, an ingestion process and another place where scope or deletions can drift. If these questions become frequent, build the graph from published notes, attach each edge to a note revision, and rebuild from those sources. Keep private Thoughts out of that ingestion path. [Neo4j indexes](https://neo4j.com/docs/cypher-manual/current/indexes/) · [Neo4j MCP](https://github.com/neo4j/mcp) · [Graphiti](https://github.com/getzep/graphiti)

## Ranking

Self-hosting or running entirely on the operator's machine is the entry requirement. The ordering is a judgment for AbraCode. It favors scoped retrieval from a fresh agent, independently editable evidence, dependable writes and recoverable operation. Skill fit means how directly someone can recover the trigger, steps, limits and proof for a reviewed skill. A memory framework can suggest similar facts. Confirming that two procedures are equivalent still takes evidence.

The interface column names a concrete local integration route. A product with an API can be wrapped in AbraCode tools without giving the model the raw API. “Model” refers to what the memory service needs beyond the agent already running. A model using retrieved text is already doing retrieval-augmented generation in the broad sense. A separate generation service or vector index is optional for many of these choices.

## From a lesson to a skill

A worker reports the trigger, procedure, limits and evidence from its assignment. Abra searches for earlier lessons and shows the operator the proposed wording and destination. After publication, another worker can cite the exact revision and test the procedure again. When independent runs establish where it works and where it fails, the operator can request normal development work to author and review a package-owned skill. This gives the project a deliberate promotion path and preserves the evidence that justified it. [Engineering workflows](engineering-skills.md)
