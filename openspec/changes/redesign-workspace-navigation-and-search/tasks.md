**Two corrections to the sketches apply throughout.** Wide-screen task and evidence inspection always brings the live chat and usable composer alongside the right reader, including when entered from Work or Search. A draggable divider shares one saved percentage per browser across views, sessions and tabs.

**Theme handoff.** Use the operator's brief recorded in the proposal for `simplify-workspace-theme-and-chrome`. This plan owns the layout and uses shared semantic tokens. The companion owns token values, typography, mark, compact chrome and empty-state styling. Its dark starting values are canvas `#101010`, composer/menu `#191919`, hover/selection `#262626`, divider `#303030`, secondary text `#A6A6A6` and primary text `#EBEBEB`, with a muted forest accent and independent focus color. Use the updated phone destinations and keep the composer reachable. Both changes can land independently.

**Component decision.** Add one Base Nova registry component, **Resizable**, for a horizontal panel group with a keyboard- and pointer-operable vertical handle. The current inspector's range input changes component-local state initialized to 39%. Use the existing **SearchDialog** (Base UI Dialog + Autocomplete) for grouped search, its existing autocomplete primitive for slash suggestions, **Sheet** for tablet, **Tabs/NativeSelect** for sections and filters, route links in semantic navigation for rail/bottom bar, and **Card/Button/Badge/Alert/Skeleton/Tooltip** for source cards and states. Sidebar, Command, Drawer and Slider would duplicate these behaviors. [Shared component exports](../../../packages/presentation/package.json) · [Existing picker](../../../packages/presentation/src/ui/search-dialog.tsx) · [shadcn Resizable](https://ui.shadcn.com/docs/components/base/resizable)

- [ ] 1.2 Build the desktop destination rail, tablet menu and phone bottom navigation using semantic route links. Compose existing Chat and Inspector into one wide-screen split for all task/evidence entry points. Preserve native form edits by binding, transcript anchor, unsent draft, theme and focus on navigation and breakpoint changes. At 1250/1251 and 760/761 px verify the same target and draft survive, and only the active controls take focus.
- [ ] 1.3 Dry-run the repository-pinned `shadcn@4.23.0 add resizable --cwd apps/web --dry-run` following `docs/frontend.md`. Review the registry output, add the shared wrapper to `packages/presentation/src/ui`, export it, and account for its `react-resizable-panels` dependency, lockfile and notices. - [ ] 1.4 Persist one validated reader percentage under a single unscoped browser-storage key. Reuse the theme provider’s cross-tab storage-event pattern. Document scope and defaults.

## 3. Deliver global Search and draft commands

- [ ] 3.1 Define a discriminated search result with stable source identity, parent/context, display label, effect and validated target. Extend `workspace-palette.tsx` and the shared picker to query the existing Work, notebook, GitHub, Settings and current-obligation owners independently. Use bounded previews, exact ID/name ranking, per-source slots, filter/prefix parsing (including `thought:`, `session:` and `>`), source-specific More, cancellation and retry. Revalidate owner and generation on open. Test duplicate titles, an exact closed ID beyond page one, late replies, a failed notebook, merged PRs, private snippets and no false zero results. Document query syntax and coverage.
- [ ] 3.2 Add cross-task session discovery to the shared HTTP contracts and authorized native read path. Page retained issue/session associations using OpenCode session identity and scoped metadata. Return role, owning task/repository and availability without fetching every transcript. Use the same read in Work → Sessions and Search. Test a worker outside the bootstrap page, retired/missing evidence, foreign association and central Abra session. Verify selecting a worker opens its exact read-only history beside Abra on desktop.
- [ ] 3.3 Create one command catalogue consumed by palette, buttons, empty Chat and the composer. Declare aliases, prerequisites, exact context and effect per command. Wire Onboard repository, Save thought, Attach thought, contextual pause/resume/advance, open decision and report actions. Add an attributed fenced-snippet insertion for selected code. Use the existing draft owner and preserve pending admission, attached evidence and existing prose. Test `add project` and `/onboard-repo` yielding identical editable drafts, over-limit insertion leaving the draft intact, and zero sends/approvals from selection.
- [ ] 3.4 Add `/onboard-repo`, `/save-thought` and `/attach-thought` as explicitly selected composer suggestions. Consume only the chosen command token. Support pointer/keyboard choice and Escape, bypass paste/IME and fenced code, and avoid Enter sending during selection. Verify search from direct Settings and tablet inspector, no competing modal, focus restoration, phone keyboard clearance and a half-written draft through both entry points. Update the search and composer guide with working examples.
