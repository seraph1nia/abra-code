# Review consequential decisions in one place

## Outcomes

Chat announces a decision. The focused canvas presents the choices and the action together.

## Recommendation

Explore groups related product and risk tradeoffs into one editable set of recommendations.

## Risks

An unexpected canvas could interrupt reading or typing. Open it automatically only in idle desktop Chat.

## Alternatives considered

1. Open every canvas manually. This adds a click when someone is waiting for a decision.
2. Move decisions to Attention. This separates a question from the conversation that prompted it.

## Acceptance

Accept an open batch in one action and understand a revision without opening a source file.
