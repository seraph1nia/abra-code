# Proposal

## Why

A full-codebase audit revealed critical security, concurrency, and protocol defects—including a symlink bypass of protected control files, unsanitized offline SVG injection, broken live AG-UI token streaming with 2× transcript transmission, lock-holder startup hangs, and global-lock I/O blocking—alongside extensive legacy compatibility scaffolding (A2UI v1–v4 catalogs, legacy HTML reports, v0→v1 plugin record migrations, SQLite v1–v11 `ALTER TABLE` ladders, retired TUI RPC wrappers, and dual Promise/Effect layers) that prevents idiomatic use of Effect 4.1.4, OpenCode 2.3.0, A2UI v1.0, and CopilotKit v2 / AG-UI 1.0.4. Because AbraCode is greenfield, dropping all legacy compatibility paths lets us fix every defect and adopt clean native designs across the entire stack.

## What Changes

- **P0 Security, Concurrency & Data Integrity:**
  - Validate `.git`/`.opencode`/`AGENTS.md` write guards against both unresolved and symlink-resolved realpaths (case-insensitively), enforce strict SVG allowlist sanitization and `#abracode-report-diagrams` digest verification, inject offline report payloads safely at the tail of `shell.html` instead of first-match `</body>`, reject relative URLs in `CatalogMedia` and `openUrl`, and enforce Supervisor principal checks in `assertApprovalActor` and `Obligations.resolve`.
  - Replace raw `spawn` lock-holder management with Effect 4.1.4 `ChildProcess.make`, move Memos HTTP lookup out of the global exclusive controller lock, stop `provision()` from clobbering global project `verification` config, guard `pause()` with `control_generation`, wrap `Operations.owned` `"uncertain"` cleanup in `Effect.uninterruptible`, unwedge `PersonalThoughts.save` on verified 404, lock `AttentionService.disposition("retry")`, fix `capacity_reservation` leaks across `sessions.ts`/`external-validation.ts`/`messages.ts`, preserve `retry` text across all resumable phases, and fix `cockpit.tsx` `statusTone` collisions, `tokens.css` WCAG AA contrast, and missing root/route React `ErrorBoundary` coverage.
- **Greenfield CopilotKit v2 & AG-UI 1.0.4 Streaming (**BREAKING**):**
  - Switch `apps/web` to consume AG-UI `agent.messages` / `OnMessagesChanged` as the sole live transcript channel and **remove** duplicated `messages` from `state.workspace`.
  - Emit lightweight AG-UI `ACTIVITY_SNAPSHOT` references (`abracode.surface`, `abracode.review`, `abracode.artifact`) instead of smuggling presentation metadata through `state.workspace`.
  - Split `WorkspaceFeed` state vs token-delta channels, pause the 5s polling fallback when zero browsers are connected, fix dropped `fleet`/`presentations`/`admissions` invalidations and lost `finishRead` `repair` signals, fix `NativeAgentAdapter.run()`/`stop()` and `observation-transport.ts` `/stop` aborts, preserve safe domain error messages and HTTP `400`/`404`/`409`/`503` status codes in `server.ts`, single-flight and retry `NativeWebBackend` across service restarts, wrap the workspace with `CopilotChatConfigurationProvider`, lift `useRenderToolCall()`, and delete `review-api.ts`, dead `webGateway.{receipts,surfaces}` RPCs, and dead `POST /api/copilotkit/info`.
- **Greenfield A2UI v1.0 Catalog, Reviews & Offline Reports (**BREAKING**):**
  - **BREAKING:** Drop A2UI v1–v4 historical catalogs, legacy `/catalog/work-v1..v4.json` routes, `LegacyReceiptSchema`, `web/surface-legacy/`, `LegacyHeadSchema`, `LegacyReportSnapshotSchema`, `legacy-html.ts`, and the custom `@`-prefixed component key shim.
  - Derive one canonical A2UI v1.0 catalog natively via `basicCatalog.derive(...)` (retaining `BasicCatalogThemeSchema` and single-pass SDK + domain validation) and keep one stable `MessageProcessor` per `surfaceId` updated via `updateComponents` and `updateDataModel`.
  - Migrate interactive `ReviewControls` onto A2UI v1.0 `ChoicePicker`, `TextField`, and declarative `checks` plus a single custom `DesignChoiceGroup` bound through `@a2ui/react`'s Generic Binder; move live work bindings out of monolithic React `ViewContext` into `DataModel` / scoped signals; replace hand-rolled regex `A2uiMarkdown` with a pure-React `markdown-it` token AST renderer; fix `DiagramBatch` cancellation, shared-browser timeout, and `line: 0` schema crashes; fix `Reviews.capture` partial reads and `Reviews.submit` lock-held full-list scans.
- **Greenfield OpenCode 2.3.0 & Effect 4.1.4 Deepening (**BREAKING**):**
  - **BREAKING:** Drop plugin record v0→v1 migrations (`storage/migrations.ts`, `legacy-original/`), SQLite v1–v11 `ALTER TABLE` migration ladders (initialize fresh schema v1 directly), legacy `createExecution` overload, `memory/` Promise wrappers, retired TUI `StandardSchemaV1` RPC wrappers, `kind: "mcp-elicitation"` form tags, and 12 legacy `scripts/*.ts` CLI wrappers.
  - Route in-process `ctx.{agent,model,skill,plugin,session}` calls directly on `Plugin.Context`, map OpenCode 2.3.0 `_tag` errors to declared domain codes, isolate startup profile loading, wire `OpenCodeAgents` into `Crew`, exclude worker/lead-only tools from Abra's supervisor policy, and unify redacted `Tool.Error` + `strictInput`.
  - Migrate core runtime infrastructure (`Locks`, `Coordination`, `Records`, `WorkGraph`, `Operations`, `GithubInbox`, `MemoryProvider`, `InboxDetailCache`, `AgentMemory`) to scoped `Context.Service` + `Layer.effect` modules, replace `Effect.orDie` finalizers with native `FileSystem` / warning handlers, fix `Agent.prepare` context-merge precedence and `monitor.ts` error isolation, configure `"effecttsgo/unstable-api-usage": "off"` in `vite.config.ts` (removing 72 file-top disable headers), and fix `@effect/atom-react` `promiseExit` races, `Atom.keepAlive` leak, `review-state.ts`, `CanvasRefresh`, and React 19 / TanStack Router performance regressions.
- **Deep-Module Consolidation & Write-Amplification Reduction:**
  - Consolidate `Records` write surface to single-read coordinated commits with an active-execution index, dirty-check `obligations.recheckCurrent` and `finishing-dispositions.collectPendingDecisions`, split god modules (`leads`/`leads-control`, `web/backend`, `web/server`, `web/reviews`, `reporting/visual-reports`, `workspace-palette`), migrate `ensure()`/`CrewError` incrementally to typed `Data.TaggedError` unions, and stabilize `file-locks.test.ts` and `frontend-lint.test.ts`.

### Modified Capabilities

## Impact

Changes span `@abracode/contracts`, `@abracode/agents`, `@abracode/presentation`, `@abracode/runtime`, `apps/web`, `apps/report`, `scripts/`, `vite.config.ts`, `package.json`, and the test suite. Existing pinned dependencies (`effect@4.1.4`, `@effect/platform-node@4.1.4`, `@effect/atom-react@4.1.4`, `@opencode/*@2.3.0`, `@a2ui/*@0.15.0`, `@a2ui/agent@0.1.0`, `@copilotkit/*@1.88.0`, `@ag-ui/*@1.0.4`, `markdown-it`) already provide every required capability; root `zod` and legacy wrapper scripts are removed. Existing pre-greenfield SQLite databases, v0 plugin records, v1–v4 A2UI surfaces, and legacy HTML reports are intentionally unsupported and require a fresh `.abracode/` state directory.

## Scope and Choices

- **Authority boundaries preserved:** OpenCode 2.3.0 remains the sole session/worktree/form/permission/tool-loop authority (`CopilotRuntime` `a2ui` middleware remains disabled and server-authoritative forms/permissions are not replaced by client-side `useHumanInTheLoop`). SQLite remains the work graph authority; OpenSpec remains the planning authority.
- **Clean slate over migration:** Because the user confirmed greenfield fresh-start semantics, all historical schema migration ladders (`storage/migrations.ts`, SQLite v1–v11 `ALTER TABLE` blocks, v1–v4 A2UI catalogs, `legacy-html.ts`, `LegacyHeadSchema`, `LegacyReceiptSchema`, `LegacyReportSnapshotSchema`) are deleted rather than wrapped in compatibility adapters. Existing tests asserting legacy upgrade/migration behavior will be updated or replaced with greenfield contract tests.
- **Sequencing:** Implementation proceeds in five verifiable waves (P0 security/concurrency/UI fixes → AG-UI/CopilotKit streaming → A2UI v1.0 catalog/reviews/reports → OpenCode 2.3.0 & Effect 4.1.4 deepening → deep-module consolidation, write-amplification & frontend/test hygiene), landing tests and documentation updates inside each wave.
