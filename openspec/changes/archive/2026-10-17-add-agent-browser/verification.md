## Operational scope

One local dependency and one registered portable skill supply browser access; no global CLI or external skill suite was installed. Chrome setup was explicit. Screenshot directories are scratch storage, not durable report attachments. The CLI is trusted same-user automation, not filesystem isolation. Rollout to a running service should happen while workers are idle; uncertain admissions retain their existing evidence. Generated OpenSpec instruction formatting was corrected with the user's explicit approval, with no intended instruction changes.
