# Tasks

The technical choices are in `proposal.md`; acceptance scenarios are in the three capability deltas. Preserve the existing runtime endpoints, controller gates and immutable evidence throughout. Group 1 deepens immutable report files and proves reduced caller knowledge before broader work. Groups 2–4 fix binding correctness; group 5 deepens browser observation; group 6 extracts the backend adapter before group 7 strengthens streaming. Group 8 verifies the combined result. For each refactor, record the before/after caller protocol, where each invariant lives, and success/conflict/recovery evidence through the same interface callers use; a new wrapper alone is insufficient.

Run `report-document-publication.test.ts`, `report-exports.test.ts` and applicable legacy artifact regressions, asserting original bytes/hashes/identities and conflict preservation. Document the before/after caller responsibilities, single owner of each file invariant, tested crash windows and remaining owner policies in `docs/architecture.md` and `docs/reports.md`; verify both real callers no longer coordinate path → stage → digest → link → verify → cleanup before proceeding to the remaining refactors.
